# v0.3.1 侧栏命令编辑器交互优化

以用户提供的左右对比图右侧为设计目标，不更换命令树和终端执行架构。

## 视觉和交互

- 全中文表单：面包屑、字段名称、步骤、错误提示、高级设置、保存状态。
- 间距基于 4 / 8 / 12 / 16 像素；卡片圆角、轻边框与 VS Code 主题变量匹配。
- 命令步骤显示圆形编号 + 可选步骤名称（如“构建”）；步骤标题保存到 `steps[].title`。
- 仅在悬浮或聚焦时显示操作：步骤上移、下移和删除；第一个/最后一个禁用无效方向。
- “添加步骤”使用通栏虚线按钮；限制最多 32 步。
- 每步带“换行执行”复选框，只有最后一步可取消勾选，与 v0.3.0 执行机制保持一致。
- 错误就近显示：命令名称、各步骤命令、工作目录、图标、环境变量等错误标记为红框并在字段下方显示说明。
- 高级设置默认收起，工作目录下提供 `${workspaceFolder}`、`${fileDirname}` 快捷插入变量。
- 保存按钮占满宽度；保存后保持编辑状态与光标，显示成功提示并在 2 秒后自动隐藏。
- 兼容较窄侧栏及键盘操作；支持 VS Code 深浅色主题。

## 数据兼容性

原有 `command`、`steps[].command`、`steps[].execute` 均保留。只增加可选字段 `steps[].title`（最多 64 字符）。读取旧配置不需迁移，导入导出仍使用 `version: 1`。

## 验收要点

1. 点击编辑后无需连续对话框即可一次修改所有命令字段。
2. 上移、下移、删除步骤后，编号与提交顺序保持一致。
3. 新增命令与旧格式命令均可正常保存，步骤标题不会丢失。
4. 空名称/空步骤/无效 JSON 在对应输入框附近出现错误，不丢失其它草稿数据。
5. 提交成功后出现“已保存”状态并在 2 秒后消失，不再重置编辑表单。
6. 工作目录变量按钮在当前光标位置插入模板变量。
7. 控件在 VS Code 窄侧栏布局下不水平溢出。
