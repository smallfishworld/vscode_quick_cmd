1默认状态：只有“分组”视图

“命令编辑”视图由 when: quickCmd.editing 控制，默认隐藏——未开始编辑时侧栏只有“分组”视图。 工具栏 8 个按钮依次为：新建分组、新建命令、搜索、导入、导出、折叠全部分组、刷新、设置（顺序取自 menus.view/title 的 navigation@0…8）。

2编辑状态：命令编辑展开覆盖分组视图

开始编辑时宿主执行 quickCmd.editor.focus（src/editor.js 的 focus()）， VS Code 展开“命令编辑”并滚动到它，“分组”被收起为标题栏，编辑表单占据整个侧栏——不是两者各占一半。 编辑视图标题栏工具栏为“在主编辑区打开”“保存并完成编辑”（✓，保存后退出）与“关闭编辑”（×，放弃确认）；webview 内部还有一行上下文（构建 · 编辑命令）与展开/重读按钮。
